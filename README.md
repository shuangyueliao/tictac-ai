# Tic Tac Pro · Hand-Drawn Tic Tac Toe vs AI

Free single-file HTML5 board game. Classic tic tac toe against a tuned AI
with hand-drawn stroke animations, three difficulty levels (Easy, Normal,
Impossible — full minimax, mathematically unbeatable) plus Ultimate mode:
nine boards at once, where every square you pick sends your opponent to
the matching board. Win/loss/draw records saved per mode and difficulty.

**Play:** https://shuangyueliao.github.io/tictac-ai/

- Mouse / touch, procedural WebAudio sounds, mute toggle
- Procedural canvas visuals (paper theme), no dependencies, one HTML file
